# COLORPOP: COMPLETE CODESPACES BUILD SPECIFICATION

## Goal
Build a functional mobile-first AI roleplay chat app named ColorPop based on the provided visual reference PNGs. This is NOT a color palette app. Use the assets in /public/assets as visual reference and decorative artwork; build all actual controls, labels, links, menus and cards as semantic HTML/React elements. Do not place transparent clickable regions over screenshots. Use the supplied 02_lucious_emmy_hero.png as a temporary hero artwork crop, but replace with a clean standalone hero asset later if possible. Do not stretch or crop the couple in ways that distort anatomy. The screenshot crops contain baked-in UI elements and are reference-only unless expressly called out as decorative artwork.

## Recommended stack
Vite + React + TypeScript, CSS custom properties (plain CSS is fine), lucide-react for icons, React Router for routes, localStorage for prototype persistence. Build responsive UI and functional navigation first; AI provider, authentication and Supabase integration come later. Avoid hard-coded demo messages that appear to be genuine user data; mark seed chats as DEMO. Keep credentials in environment variables, never frontend source.

Main container width min(100% - 24px, 1440px). Mobile horizontal padding 12px, gap 12px; desktop padding 24px, gap 16px. Minimum tap target 44x44px. Font sizes: body 14-16px, small captions 11-12px, section titles 23-28px, hero headline 28-36px, desktop hero headline 44-60px. Cards border radius 22-30px; buttons pill radius 999px; icon circles 52-60px mobile, 62-76px desktop. Use a consistent 1px translucent pink border, layered inset highlights and soft pink outer glow, sparingly applied for legibility.

## Functional behavior
Every button must work. React Router routes: /, /chats, /chats/:id, /characters, /characters/new, /lorebooks, /lorebooks/new, /personas, /personas/new, /saved, /settings, /gallery, /plugins. Show intentional empty states for no user data. Quick links open their configured destinations. Search opens searchable overlay. More opens a menu. Creation cards open forms with Save/Cancel; prototype content persists to localStorage with stable IDs. Recent chats load from persisted data, with explicit demo placeholders when empty. Provide reusable Card, GemIcon, Sparkle, QuickLink, ChatPreview, NavBar, SectionHeader components. No AI or real chat backend should be simulated as live without disclosure.

## Visual effects and accessibility
Shimmer is CSS pseudo-elements, not image-only. Example ring: border 2px solid rgba(255,255,255,.65); box-shadow 0 0 0 3px rgba(255,0,134,.2), inset 0 2px 6px rgba(255,255,255,.55), 0 0 18px rgba(255,0,134,.5). Diamond-like tiny 4-point star shapes can be CSS or inline SVG around circles, outside their bounds; pointer-events none. Keep contrast sufficient against glossy backgrounds. Keyboard focus-visible outlines, alt text for images, accessible names for icon-only buttons, no layout shift. Use responsive images, lazy loading below fold, avoid giant background PNG downloads.
